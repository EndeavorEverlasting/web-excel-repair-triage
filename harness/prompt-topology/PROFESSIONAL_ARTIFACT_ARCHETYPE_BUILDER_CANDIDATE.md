## Whole-chat harvest — pass 2

Reverse traversal caught the following requirements that were easy to lose:

1. **Artifact delivery must be visible.** The final response leads with the actual artifact link/path, not a long process report.
2. **Do not make spreadsheets generic Google Sheets artifacts.** Acceptance follows the declared runtime; Excel desktop/Web is primary when Excel is the real target.
3. **Stable identity matters as much as appearance.** Reuse canonical artifacts and avoid duplicate CURRENT files/workspaces.
4. **Aesthetic correction must become machinery.** Manual live formatting is only a prototype when the same rule should recur.
5. **Prototype tests must be stable across iterations.** A later candidate cannot “pass” by changing the rubric to fit itself.
6. **Visual authority can be a rendered screenshot.** Raw file internals do not outrank the operator-verified visible appearance when themes invert.
7. **Shared design language must support different operational schemas.** Meeting notes, sign-offs, tutorials, ledgers, trackers, SOPs, and OTHER must remain structurally honest.
8. **Brand comes after generic fidelity.** H&H is a concrete motivating instance, not a hard-coded first-class concept in the reusable prompt.
