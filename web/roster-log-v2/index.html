OPERATING RULE

Attendance owns hours. Allocations own project attribution.

The default / fallback project is used only when no explicit project allocation exists for that paid day. Once allocations exist, those rows are the project truth. A deliberate full-day project decision, a two-project split, or a three-project split are all valid when the allocation arithmetic reconciles.

Allocation basis explains why a row exists: DEFAULT is fallback-created, EXPLICIT is intentionally entered, and OVERRIDE intentionally corrects a default or prior classification. The tracker does not invent an 80/20 split or infer an override.

Everything stays in this browser's local storage until you export it. JSON is the canonical portable state consumed by the repo workbook generator; report exports are deterministic projections of that state.
