OPERATING RULE

Attendance owns hours. Allocation explains them.

A deliberate full-day project decision is valid input. An 80/20 split is also valid input. This tracker does not invent either one. It records the operator's project decision, permits additional project rows, and highlights only unreconciled totals.

Everything stays in this browser's local storage until you export it. The JSON export is the canonical local artifact consumed by the repo workbook generator.
